# Sourcyn - AI Procurement & Vendor Intelligence Platform - Backend

Production-ready backend API and asynchronous multi-agent evaluation orchestrator.

## Tech Stack
- **FastAPI**: Modern, high-performance web framework.
- **Pydantic v2**: Strict schema validation and structured outputs.
- **SQLAlchemy 2.x & Alembic**: Database ORM and migrations.
- **PostgreSQL 16 + pgvector**: Multi-tenant relational storage and vector search.
- **Redis 7**: Cache, distributed locks, and pub/sub streaming.
- **LangGraph**: Stateful multi-agent orchestration and human-in-the-loop workflows.
- **MinIO / AWS S3**: Quotation document and artifact object storage.
